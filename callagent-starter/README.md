# Call agent (Space CorpAcc with MTS, Track 1)

Local, Russian-speaking AI assistant that answers calls Ivan cannot take and reports to him in Telegram and a dashboard.

Start here: `AGENTS.md` (rules for people and AIs), `docs/REQUIREMENTS.md`, `docs/ARCHITECTURE.md`, `docs/WORK_PLAN.md`, `prompts/ANTIGRAVITY_PROMPTS.md`.

First steps: create a git repository from this folder, copy `.env.example` to `.env` and fill the keys, install Ollama and pull a model, then run Prompt 0 from `prompts/ANTIGRAVITY_PROMPTS.md`.
